# Starlicht — онлайн-кінотеатр (React SPA)

Стек: React 19, TypeScript, Redux Toolkit (RTK Query), React Router 7, Vite.

## Запуск

```bash
npm install
npm run dev        # режим розробки
npm run build      # tsc -b + vite build
npm run preview    # перегляд збірки
npm run lint
```

## API

Без налаштувань застосунок працює на вбудованих демо-даних (`src/api/mock.ts`).
Щоб підключити реальні дані з TMDB, скопіюйте `.env.example` у `.env` і вкажіть `VITE_TMDB_KEY`.

## Зображення

Зображення не зберігаються в проєкті — браузер підбирає їх сам (`src/lib/images.ts`) і кешує адреси в `localStorage`:

- **Фільми, серіали, мультфільми** — TMDB (якщо задано `VITE_TMDB_KEY`, найточніший варіант), інакше постер зі статті у Вікіпедії.
- **Спорт** — фото з Wikimedia Commons за видом спорту.
- **Телеканали** — логотип зі статті у Вікіпедії.

Збіг назви лише точний; якщо зображення не знайдено, показується градієнтна заглушка. Вимкнути підбір: `VITE_IMAGES=off`.
Постери — власність їхніх правовласників; для публічного сайту використовуйте TMDB з вказівкою джерела або власні файли.

## Сторінки та маршрути

| Сторінка | Маршрут | Доступ |
| --- | --- | --- |
| Дім | `/` | відкритий |
| Каталог | `/catalog/:type` (`movies`, `series`, `cartoons`) | відкритий |
| Пошук | `/search?q=` | відкритий |
| Деталі фільму | `/movie/:id` | відкритий |
| Підписка | `/subscription` | відкритий |
| Новини | `/news` | відкритий |
| Вхід / Реєстрація | `/login`, `/register` | відкритий |
| Плеєр | `/watch/:id` | **захищений** |
| Улюблені | `/favorites` | **захищений** |
| Історія | `/history` | **захищений** |
| Профіль | `/profile` | **захищений** |

## Можливості

- Захищені маршрути (`ProtectedRoute`) з поверненням на цільову сторінку після входу.
- Перемикач теми (темна/світла) і локалізація (УКР/ENG), вибір зберігається в `localStorage`.
- Адаптивний макет (від 360px до десктопа).
- Відеоплеєр: пауза, перемотування ±10 с, гучність, швидкість, **Picture-in-Picture**, **повний екран**, гарячі клавіші (K, M, I, F), продовження з місця зупинки та запис в історію.

## Автентифікація

`src/api/authApi.ts` — **демо-імітація** бекенду на `localStorage` (код підтвердження: `358564`).
Паролі хешуються SHA-256 без солі, тож це не production-рішення: замініть модуль на запити до вашого сервера.
